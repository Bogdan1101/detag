# ДЕТАГ — современный сайт на React и TypeScript

Обновлённый сайт с исходным логотипом, адаптивным интерфейсом, каталогом, поиском и локальной корзиной. Тексты, фотографии и характеристики перенесены с публичного `detag.ru`, снимок от 12 октября 2026 года.

**Стек:** React 19, TypeScript 5, Vite 7. Для приложения не требуются Joomla, PHP или база данных.

## Запуск

Нужен Node.js 22.12+; в облачной среде проверен Node.js 24.19.0.

```sh
cd /workspace/detag
npm ci --cache /workspace/.cache/npm
npm run dev -- --port 5173
```

На своём компьютере перейдите в папку распакованного проекта, выполните `npm ci` и `npm run dev`. Параметр `--cache /workspace/.cache/npm` нужен только для облачной среды с ограничением записи в домашнюю папку.

```sh
npm run build
npm run preview -- --port 4173
```

Сборка проверяет TypeScript и создаёт готовый сайт в `dist/`. Установка зависимостей использует `package-lock.json`. Сервер разработки и preview предназначены для разработки и проверки, для публикации используйте статический хостинг.

## Что перенесено и работает

- 19 товаров с исходными фотографиями, описаниями и характеристиками.
- 12 категорий, информационные страницы, контакты, архив новости EuroShop 2017 и исходные юридические тексты.
- Главная страница, каталог, карточки товаров и навигация для компьютеров и телефонов.
- Поиск по словам в названиях, категориях и характеристиках; сортировка по названию.
- Просмотр увеличенной фотографии товара; закрытие диалогов клавишей Escape.
- Корзина: добавление, изменение количества и удаление. Список сохраняется локально в браузере; есть предел 999 единиц на позицию.
- Запрос стоимости: открывается почтовая программа с перечнем выбранных товаров. Письмо пользователь проверяет и отправляет самостоятельно.
- Консультация: подготовка письма с именем и вопросом, ссылки на телефон, почту, Telegram и WhatsApp.
- Все 57 обнаруженных адресов старых страниц, включая альтернативные адреса категорий `/component/virtuemart/…`.

На исходных карточках цены не опубликованы, поэтому указано **«Цена по запросу»**. Онлайн-оплата, серверные заказы, учётные записи, подписка и автоматическая отправка форм не подключены. Корзина и подготовка писем работают без сервера и не заявляют о создании заказа. Старые счётчики, чат и reCAPTCHA не перенесены в новое приложение.

## Где редактировать

| Файл / папка | Назначение |
| --- | --- |
| `src/App.tsx` | Страницы, компоненты, маршрутизация и логика корзины |
| `src/styles.css` | Оформление и мобильная адаптация |
| `src/data/content.json` | Названия, категории, характеристики, тексты и адреса страниц |
| `src/data/promotion.json` | Заголовок, условия, минимальная сумма и изображение акции |
| `src/promotions.css` | Большой баннер акции и дополнительные стили карточек |
| `public/images/` | Исходные фотографии и логотип |
| `index.html` | Заголовок по умолчанию, описание сайта и HTML-оболочка |
| `archive/` | Исходные ответы сайта без правок, 220 файлов |
| `snapshot/` | Статическая копия старого оформления, 57 страниц |
| `reports/mirror.json` | Полный список скачанных URL, статусы и SHA-256 |
| `reports/modern-browser.json` | Результаты проверки нового сайта |
| `reports/modern-*.png` | Скриншоты нового сайта |

Для изменения товара отредактируйте его запись в `src/data/content.json`. `id` — ключ корзины, `path` — сохранённый адрес страницы, `categoryId` и `groupId` — категория и её основная группа. `price` пока равен `null`; для публикации цен понадобится соответствующая логика интерфейса. Поля `contentHtml` и `descriptionHtml` содержат очищенный HTML исходных текстов; добавляйте в них только проверенное содержимое.

Текст новости 2017 года обозначен как архивный. Информация об акциях, клиентах, доставке и партнёрстве взята из прежнего сайта; перед публикацией проверьте её актуальность. Юридические тексты сохранены из оригинала и могут требовать обновления под будущую обработку заявок.

## Проверка

```sh
npm run build
python tools/browser_check.py
```

Браузерная проверка требует Python, Playwright и системный `chromium`; они доступны в подготовленной облачной среде. Скрипт по умолчанию проверяет запущенный сервер разработки на порту 5173. Проверить сборку, запущенную через preview:

```sh
python tools/browser_check.py http://127.0.0.1:4173
```

Проверяются все 57 старых адресов, загрузка изображений, отсутствие ошибок JavaScript и запросов к внешним ресурсам, поиск, сортировка, корзина и её сохранение, содержимое черновиков писем, просмотр фотографий, мобильная навигация, отсутствие горизонтальной прокрутки на проверенных страницах и обработка неизвестных адресов. Проверка не отправляет письма и не размещает заказы.

## Размещение

Загрузите **содержимое `dist/`** в корень нового сайта. Хостинг должен отдавать `index.html` для отсутствующих файлов: маршруты страниц обрабатывает React. В `public/_redirects` сохранено правило для хостингов с поддержкой такого формата, оно попадает в сборку.

Для Nginx добавьте в конфигурацию сайта:

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

Публикация на `detag.ru` потребует доступа к домену и хостингу. В текущей работе создана локальная копия; существующий сайт на домене не изменён. Для автоматической отправки заявок потребуется отдельно подключить новый обработчик или систему управления.

## Исходный архив

Сохранено всё, что найдено переходом по публичным ссылкам. Скрытые страницы без ссылок, исходники Joomla, база данных, заказы и доступ к административной панели не восстанавливаются из публичного сайта.

На исходном сервере отсутствуют 47 файлов шрифтов и 4 изображения доставки: `/images/dostavka-1.jpg` — `/images/dostavka-4.jpg`. Они возвращают HTTP 404, список зафиксирован в `reports/mirror.json`. Новое приложение использует системные шрифты и не ссылается на отсутствующие изображения. Все обнаруженные HTML-страницы скачались успешно.

Для просмотра старой статической копии:

```sh
python -m http.server 8001 --directory snapshot
python tools/validate_snapshot.py http://127.0.0.1:8001
```

В архиве хранится исходный HTML; в `snapshot/` ссылки заменены локальными, отключены внешние счётчики и обработчики прежней CMS, добавлены локальный поиск и просмотр изображения. Контрольные суммы в отчёте относятся к `archive/`.

Для повторного скачивания публичного оригинала и пересборки старого снимка:

```sh
python tools/mirror.py
```

Для пересборки старого снимка без сети:

```sh
python tools/mirror.py --rebuild
```

Скрипт использует стандартную библиотеку Python, проверяет TLS, выполняет только GET-запросы и не отправляет формы. Он обновляет `archive/` и `snapshot/`, не перезаписывает React-приложение. Источники ресурсов: `detag.ru`, `www.detag.ru`, `ajax.googleapis.com`.

`tools/extract_content.py` использует `lxml` и заново извлекает данные из архива в `src/data/content.json`. Его не нужно запускать при обычной установке; перед повторной миграцией сохраните свои правки содержимого отдельно.
